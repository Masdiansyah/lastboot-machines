A premium static website concept built from the supplied LASTBOOT MACHINES blueprint and logo.

- Core concept: digital archaeological archive
- Vibe: retro-computer + abandoned technology + cyberpunk archive
- Brand line: THE MACHINES THAT REMEMBER.
